# 🍎 DSA Panel for MacOS

A powerful, native-feeling MacOS utility designed for developers to track, manage, and solve Data Structures and Algorithms (DSA) problems efficiently.

![License](https://img.shields.io/github/license/maisachinsharmahu/dsa-panel-macos-showcase)
![Platform](https://img.shields.io/badge/platform-macOS-blue)
![Tech Stack](https://img.shields.io/badge/tech-Flutter-02569B?logo=flutter)

## ✨ Features

- **Problem Tracking**: Keep a log of all DSA problems solved across various platforms.
- **Topic Management**: Categorized view of problems (Trees, Graphs, DP, etc.).
- **Timer & Focus**: Built-in timer to simulate real interview environments.
- **Notes & Sketches**: Integrated editor and sketch board for dry-running logic.
- **Offline First**: All your data stays on your machine.

## 🛠️ Tech Stack

- **Frontend**: Flutter (MacOS Desktop)
- **State Management**: Riverpod / Provider
- **Local Storage**: SQLite / Shared Preferences
- **Architecture**: Clean Architecture / Feature-based

## 🚀 Getting Started

### Prerequisites
- Flutter SDK installed on MacOS
- Xcode

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/maisachinsharmahu/dsa-panel-macos-showcase.git
   ```
2. Navigate to the project:
   ```bash
   cd dsa-panel-macos-showcase
   ```
3. Get dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run -d macos
   ```
